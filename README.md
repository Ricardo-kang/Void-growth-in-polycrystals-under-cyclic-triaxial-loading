This project theme is cyclic triaxial loading of polycrystalline materials.
It includes four files.
File loading.lmp is used to control the cyclic triaxial loading in lammps.
File dislocation_density.py is used to calculate the dislocation density of the model.
File volume_fraction.py is used to calculate the void volume fraction of the model.
File Eamnple_T=3_L=-1_500K.txt provides the equivalent stress–strain curve of the computational results under conditions of T = 3, L = –1, 500 K.
